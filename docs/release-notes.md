# 可乐音乐 kele-music · 版本更新日志

在线音乐客户端（Flutter），一套代码构建 **Android / iOS / macOS / Windows / Linux / Web**。
后端基于开源 [api-enhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)，默认接口 `https://music.2000321.xyz`，可在「设置 → 后端服务 → API 地址」随时切换。

## v0.2.0（2026-10-23）

### 新特性

- **VIP / 无版权歌曲智能兜底播放**：播放 VIP 歌曲时官方音源不可用或仅返回试听片段，自动请求后端解灰接口 `/song/url/match` 匹配可用音源（聚合 byfuns / ddyr / gdmusic / msls / oi / qijieya / unm 等多个模块），对全灰歌单"能播尽播"。免费歌曲与可播 VIP 歌曲零额外请求；兜底音源按当前播放音质档位匹配（标准 / 较高 / 极高 / 无损 / Hi-Res）。说明：周杰伦等全网无授权歌曲仍无法播放，会明确提示「该歌曲暂无可用音源」；兜底能力依赖 api-enhanced 后端（默认地址已内置支持）。
- **播放失败全局提示**：新增播放错误广播通道，切歌 / 下一曲 / 队列点歌 / 播放键重试失败时统一弹出 SnackBar 提示，明确区分「点击无反应」与「点击了但没有可用音源」。
- **待播放列表页完善**：复用全应用共用的歌曲行组件，与歌曲列表页完全同源——新增 **VIP 标记** 与行尾**时长**（等宽数字防跳动）；当前播放曲高亮 + 均衡器图标、分隔线对齐方式与其他列表页保持一致。
- **设置页显示当前版本号**：设置底部新增「关于」板块，显示版本与 build 号（取自构建产物内嵌信息，与发布包始终一致），点击一键复制，便于与 GitHub 最新发布比对是否需要更新。

### 体验优化

- **切歌体验**：切歌立即停止旧曲并归零进度，不再出现「旧歌还在响、新歌加载中」的错位感；下一曲音源 URL 预取 + 本地缓存（10 分钟有效期、最多 32 条、并发请求去重），按顺序 / 单曲循环模式智能预取，切歌秒开；音源地址加载失败时自动强制刷新重解析一次。

### 问题修复

- **设置页操作导致声音消失 / 迷你播放条黑屏（重要）**：根因是设置页刷新时销毁并重建播放仓库，音频处理器被释放。应用根部改用全局 ProviderContainer，播放仓库脱离页面级生命周期，设置页任意操作（切主题、改音质、签到等）不再影响正在播放的音乐。
- **无音源歌曲切歌失败后「旧歌复活」**：根因是切歌失败后播放器内部仍保留旧曲状态，此时点播放键会错误恢复旧歌。现跟踪当前已加载曲目，点播放键时若当前曲未加载会自动重新解析加载，失败则提示且绝不复活旧歌。
- **设置页「恢复默认地址」无效**：根因是配置重载从「已被用户保存值污染的当前实例」起步，删除保存键后永远算不回内置默认地址。现改为从纯内置默认幂等重算；同时补齐恢复默认路径的 API 客户端同步（此前仅配置值变化，运行中请求仍走旧地址，需重启才生效）。

> 本版本产物命名沿用下文清单规则，版本号替换为 **v0.2.0**（`kele-music-v0.2.0-*`）；各平台安装说明见下文。

## v0.1.0（首版）

### 本版本内容

- **游客可玩**：不登录也能浏览推荐、排行榜、歌单详情、搜索并试听；需要同步歌单 / 收藏时再登录。
- **登录**：手机验证码 + 扫码登录（密码登录受官方风控限制，未启用）。
- **发现**：轮播、推荐歌单、排行榜、每日推荐（登录后可见）。
- **搜索**：关键词搜歌，一键起播。
- **歌单 / 榜单详情**：曲目列表点播，支持收藏。
- **播放**：迷你播放条 + 全屏播放页（黑胶 / 专辑卡 / 柔焦三套版式），支持后台播放与锁屏控制；在线音质可选 标准 / 较高 / 极高 / 无损 / Hi-Res。
- **我的**：资料卡、每日签到、退出登录。
- **设置**：三套主题风格（暖调黑胶复古 / 极简专辑卡·橄榄绿 / 柔焦梦幻青）、播放与下载音质、后端地址、清空本地历史。

### 安装说明

**Android**
1. 下载 `*-android-universal.apk`（不确定机型就用这个）。
2. 手机「设置 → 允许安装未知来源应用」授权给浏览器/文件管理器。
3. 点击 APK 安装。首次启动可先「游客浏览」，需要同步歌单再登录。

**Windows**
1. 解压 `*-windows-x64.zip` 到任意目录。
2. 双击 `kele-music.exe` 运行（需 Microsoft Visual C++ 2015-2022 x64 运行库，缺失时会提示缺 DLL）。

**macOS**
1. 解压对应架构的 zip，得到 `kele-music.app`。
2. 拖入「应用程序」；首次打开若被拦，右键 → 打开（未做 Apple 公证）。

**Linux**
1. 解压 tar 包后运行 `kele-music`。
2. 依赖：`libsecret-1-0`、`libmpv2`（`sudo apt install libsecret-1-0 libmpv2`），Ubuntu 22.04+ 可直接用。

**Web**
1. 解压 zip，用任意静态服务器托管（如 `npx serve`、Nginx、GitHub Pages）。
2. 打开首页即可游客浏览；建议用 Chrome / Edge。

**iOS**
- 产物是**未签名**的 `.app`，无法直接装到真机。需自行用 Apple 开发者证书签名（如 Xcode 重签、AltStore/Sideloadly 侧载），或等待后续提供 TestFlight / Ad Hoc 包。

### 已知限制

- Android APK 目前使用**调试签名**（未配置发布密钥）：可正常安装、覆盖升级，但不能直接上架应用市场。
- iOS 未签名：见上。
- Windows / macOS 未做代码签名，Gatekeeper 可能提示「未知开发者」。
- 应用为第三方客户端，账号安全与接口稳定性由后端与官方接口决定，请勿用于重要账号。
